# Parte de campo · IngEcAmur

App para el trabajo de campo (Android, iPhone y libreta del GPS): trabajos por medir, fichas de clientes,
fotos, notas de voz, datos GNSS (CSV) y Editor DXF. Funciona sin cobertura y sube todo a Dropbox.

Este repositorio solo contiene el programa. Los datos de clientes viven en el Dropbox de la consultora
y solo se ven tras entrar con su cuenta.
